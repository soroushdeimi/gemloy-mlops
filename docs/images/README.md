# Screenshot capture slots

Screenshots are taken after deploying; this repository currently contains no telemetry screenshots.

| Future filename | Required capture |
|---|---|
| `gpu.png` | Real GPU temperature, utilization, memory and XID panels |
| `model.png` | Real throughput, latency, running/queue and KV panels |
| `app.png` | Real status rates, latency, upstream errors and token panels |

For each image record the test environment, time range and versions. These capture slots intentionally remain empty until a real deployment is available.
